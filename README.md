# Тілдес — GitHub-қа арналған сайт

Бұл архивте сайттың соңғы нұсқасы бар: көк интерфейс, бордо жеңді 3D қол, 42 әріптің видеолары, сөздер, ойындар, камера практикасы және бес тақырыптан тұратын «Жоба туралы» бөлімі. Қосымша оқыту видеолары бөлек қосылған жоқ. Камераға арналған нүктелер мен модель файлдары енгізілген.

## GitHub Pages-ке жариялау

1. Архивті компьютерге жүктеп, толық шығарыңыз.
2. GitHub-та жаңа **Public** репозиторий ашыңыз. Атауын, мысалы, **tildes** қойыңыз. Негізгі тармақ **main** болсын.
3. **Add file → Upload files** арқылы осы папканың ішіндегі `site`, `scripts`, `.github` папкаларын және `README.md` файлын репозиторийдің түбіріне жүктеңіз. Архивтің өзін жүктеу жеткіліксіз. Репозиторий ішінде бірден `site/index.html` және `.github/workflows/pages.yml` болуы керек. Сыртқы `Tildes_GitHub` папкасын қосымша деңгей ретінде жүктемеңіз. Файлдар бір жүктеуге сыймаса, папкаларды бірнеше жүктеумен қосыңыз.
4. **Settings → Pages → Build and deployment → Source → GitHub Actions** таңдаңыз.
5. **Actions → Publish Tildes → Run workflow** басыңыз. Орындалу сәтті аяқталғанда **Settings → Pages → Visit site** арқылы сайтты ашыңыз.

Сілтеме шамамен `https://GITHUB_АТЫҢЫЗ.github.io/tildes/` түрінде болады. Репозиторий басқа атпен ашылса да, жолдарды дайындау скрипті атауын автоматты ескереді. Арнайы домен қолданылса, түбір жол да қолданылады. Файлдарды жүктеуге GitHub аккаунты қажет; жарияланған сайтты көруге ChatGPT аккаунты қажет емес.

Егер Actions «Pages site not found» қатесін берсе, 4-қадамдағы Source баптауын тексеріп, Run workflow-ды қайта басыңыз.

## Қандай файлдар бар

- `site/index.html` — басты бет.
- `site/css`, `site/js` — дизайн және бағдарламалық код.
- `site/media/videos`, `site/media/posters` — 42 үлгі видео мен мұқаба суреттері.
- `site/data`, `site/practice`, `site/camera` — 3D қалыптар, камера практикасы және сынақ моделі.
- `site/fonts` — қазақ әріптері бар қаріптер және лицензиялары.
- `scripts/build_pages.py` — GitHub Pages ішкі жолдарын дайындау.
- `.github/workflows/pages.yml` — жариялау әрекеті.

## Камера және 3D қол

Камераны HTTPS арқылы жарияланған сайтта ашып, браузерге рұқсат беріңіз. `index.html` файлын жай екі рет басып ашу камера мен модульдердің жұмысын толық қамтамасыз етпейді.

3D қол үшін WebGL қолдауы қажет. Камераны талдайтын MediaPipe модулі мен WASM файлдары jsDelivr арқылы жүктеледі, сондықтан интернет қажет. Үлгі видеолар, 3D деректері, қаріптер және модель сайтпен бірге сақталған. ChatGPT серверіне сұрау немесе ChatGPT-ке кіру қажет емес.

Бұл экспорт тану моделін қайта оқытпайды. Практика пайызы — үлгімен есептелген ұқсастық. Камерадан 42 әріпті еркін тану әлі сынақ деңгейінде.

## Сайтты кейін өзгерту

Негізгі файлдар `site` ішінде. Өзгерістерді main тармағына сақтағанда Actions сайтты қайта жариялайды.

Басқа статикалық хостингке орналастырсаңыз, `site` папкасының ішін жариялаңыз. GitHub-қа арналған `_site` папкасын қолмен дайындау қажет емес.
